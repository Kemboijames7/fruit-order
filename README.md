### **Fruit Order Portal – README**  

#### **Overview**  
The Fruit Order Portal is an interactive online platform that allows patrons to order fresh fruit directly from the grocer. It simplifies the ordering process by providing a seamless experience for selecting, customizing, and confirming fruit purchases.  

#### **Features**  
- **User-Friendly Ordering System** – Easily browse and select fruits from an updated inventory.  
- **Dynamic Order Processing** – Real-time interaction with the grocer’s API for placing and updating orders.  
- **Order Confirmation Modal** – Displays order details, estimated delivery time, and a receipt link.  
- **Success & Error Notifications** – Immediate feedback on order status.  
- **Inventory Analysis** – Tracks fruit availability and helps create discounts or promotions for surplus stock.  
- **Elegant UI Design** – A clean, minimal interface with intuitive navigation.  

#### **Technology Stack**  
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Atlas)  
- **API Communication:** Fetch API for real-time order handling  

#### **How to Run the Project**  
1. Clone the repository:  
   ```sh
   git clone <repo-url>
   ```
2. Navigate to the project directory:  
   ```sh
   cd fruit-order-portal
   ```
3. Install dependencies:  
   ```sh
   npm install
   ```
4. Start the development server:  
   ```sh
   npm start
   ```
5. Open in the browser:  
   ```
   http://localhost:3000
   ```
